## script_step 4. CONNECT TO WHAT I KNOW — NAME QUESTION VS COUNTRY QUESTION (P2)

> **教学目的**: 关联已学知识、区分两种问句功能

### Activity 4.1 · 对比已学问句
- **意图**: 【对比已学问句】服务教学目的「关联已学知识、区分两种问句功能」
- **原文锚点**: **Screen:** 你叫什么名字？ 你是哪国人？ Kai: You already know how to ask someone's name. 你叫什么名字？ Now you can ask where someone is from. 你是哪国人？ Kai: Two questions. Both help you get to know someone.
- **选型思考**: 选型思考：本活动要展示并对比「你叫什么名字？」与「你是哪国人？」，让学生观察差异，不是先做选择题。 因此优先模版能挂多句的组件（句型观察/句型学习/图文卡），下调单项选择。 推荐顺序：CMP-11 句型观察 → CMP-07 句型学习 → CMP-10 图文卡片
- **候选 components**:
  1. CMP-11 句型观察 — 适合：模版有 3 个【例句】槽，可并排呈现「你叫什么名字？」与「你是哪国人？」供观察对比；目的「通过对比自主发现结构」 (recommended, from_n1, selected)
  2. CMP-07 句型学习 — 适合：左右例句+公式支架，可对照「你叫什么名字？」与「你是哪国人？」并点出结构差异
  3. CMP-10 图文卡片 — 可用：图文卡可承载对比文案，但原型偏单点聚焦，两句并排略勉强
  4. CMP-16 图文介绍 — 可用：图文卡可承载对比文案，但原型偏单点聚焦，两句并排略勉强
  5. CMP-04 Mission发布 — 模版可承载文字

  3. CMP-33 选择题（传统版） — 可用：能做选择，但无焦点槽，弱化目标词
  4. CMP-11 句型观察 — 匹配「句型观察/对比」 (from_n1)
