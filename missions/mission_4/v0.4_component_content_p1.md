## Phase 1 校验

### 1. Display Text 严格遵循 component 模版 ✅
- 模版标 `无` 的 2 个 lesson_step（1.1 / 2.1）：Display Text = `NA`
- 其他 5 个 lesson_step（1.2 / 2.2 / 3.1 / 3.2 / 3.3）：Display Text 按模版填
- 模版里有但 lesson_step 没值的字段（如 2.2 / 3.2 的【焦点】）：填 `NA`（不用 `—`）

### 2. 关键执行点
- **CMP-04** 模版只有任务标题 + 按钮，5 goals 在 component data 中（goals[].en）—— 不混在 Display Text
- **CMP-13** 模版有【答案】行—— 保留在 Display Text 中（component 端处理可见性，模板层面要齐）
- **CMP-05** 模版每行都带拼音—— 拼音是 component 标准（不是给脚本加拼音）
- **CMP-08** 模版的 [重读] 是选填—— 我们填了，没有"重读字"就跳过

### 3. 其他 17 字段保持 v0.4.2 规则
- 脚本字段直接用源 script 原文
- 源未出现的字段用 `—`
- 答错反馈源未出现也用 `—`
