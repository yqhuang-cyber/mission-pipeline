## 1. 4-Phase 框架定义

| Phase | 名称 | 教学功能 | script_step 类型 |
|---|---|---|---|
| **P1** | Mission Intro | 任务发布、故事沉浸、首次感知目标表达 | 过渡类为主，辅以轻讲解 |
| **P2** | Knowledge Discovery | 词汇/句型/对话的发现、连接、练习、模式识别 | 讲解/探索/练习混合，教学密度最高 |
| **P3** | Performance Mission | 任务确认、故事回放、真实任务执行 | 练习类为主，AI 任务驱动 |
| **P4** | Ending Summary | 收获展示、关键表达回顾、信心自评、衔接下一课 | 过渡+回顾类 |

## 4. 判定规则（v0.2，供 script_step 2 自动 enforce 用）

```
1. 每个 script_step 必须落在 P1/P2/P3/P4 之一
2. 每个 script_step 选用的 component 必须在该 phase 的 allowed 列表内
3. 一个 script_step 可以挂 1+ 个 component lesson_step（按设计需要）
4. P1 至少要包含 CMP-04（Mission 发布）
5. P4 至少要包含 CMP-21 或 CMP-26（关键表达回顾）
6. P3 如果使用 CMP-19（AI 开放任务），必须配 CMP-18（AI Mission Setup）作为前置
7. P3 末尾如果使用 CMP-28（信心自评），只能作为该 phase 的最后 1 个 script_step
8. P4 如果使用 CMP-22（下集预告），应放在最后一个 script_step
9. CMP-03（视频播放）每次 lesson_step 必须配独立素材 objectKey，不复用
10. P1 内 CMP-13（单项选择 / single-choice-simple）**仅限短题干"含义推断"型**——问题形式必须是"X 在做什么 / 在问什么"；布局偏左焦点词 + 右选项。不能是"你会怎么说 / 你选哪个对话"
11. P1 内不允许 CMP-02（互动选择 / 对话选择）
12. **题干较长的传统单选**（Kai 铺垫后提问 + Student choices A/B/C、理解检测如"听到几个国家？"）必须用 **CMP-33**（single-choice-legacy），**不要**用 CMP-13 或 CMP-09 顶替
```

## 5. 资产规则补充

### CMP-03 视频播放 — 每次独立素材

> 决策 5：视频播放（CMP-03）每次 lesson_step 都要有自己的播放素材。
> 
> **含义**：
> - script_step 1 的开场故事视频、`script_step 2` 的开场故事视频、`script_step 16` 的故事回放 = 3 个不同 lesson_step，必须配 3 段独立视频 objectKey
> - 即使剧情相同，每次播放也是独立的 component lesson_step，资产不共享
> - 影响 v0.4 阶段：每 lesson_step 的 `video.objectKey` 必须显式标注，不可省略
